**Sitio publicado:** https://arielreynaga2662-lab.github.io/tp-sitio-gimnasio/

## Descripción del proyecto

Sitio web informativo (landing page) para el gimnasio **Zonafit Gym**, con información sobre disciplinas, galería, opiniones de socios, planes de membresía, horarios, entrenadores y un formulario de contacto.

## Objetivo

Aplicar el proceso de diseño web desde la etapa preliminar (investigación, wireframes, mapa del sitio) hasta el desarrollo y la publicación final del sitio.

## Secciones del sitio

1. Menú de navegación
2. Inicio (hero)
3. Disciplinas
4. Galería
5. Comentarios
6. Planes y precios
7. Horarios
8. Entrenadores / Equipo
9. Contacto (con formulario validado)
10. Pie de página

## Tecnologías

- HTML5 semántico
- CSS3 (estilos propios en `css/styles.css`)
- JavaScript (`js/main.js`)
- Bootstrap 5.3.3 y Bootstrap Icons (por CDN)
- Prettier 3 (formato del código)
- Lighthouse (auditoría de rendimiento y accesibilidad)
- Git, GitHub y GitHub Pages
