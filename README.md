##  Descripción del proyecto

Diseño y desarrollo de un sitio web informativo para un gimnasio, que incluye
información sobre clases, planes de membresía, entrenadores e instalaciones.

##  Objetivo

Aplicar el proceso de diseño web desde la etapa preliminar (investigación,
wireframes, mapa del sitio) hasta el desarrollo final del sitio.
